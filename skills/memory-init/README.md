# Memory Init Skill

Initialize `.memory-context/` with standard template files.

## Files Created

| File | Purpose |
|------|---------|
| architecture.md | System design and components |
| coding-conventions.md | Style guide |
| current-work.md | Active tasks |
| known-errors.md | Bug workarounds |
| testing-patterns.md | Test conventions |
| deployment.md | Deploy process |
| decisions.md | Decision log |
| observability.md | Logging/metrics |
| api-contracts.md | API schemas |
| data-models.md | Data structures |
| ci-cd.md | Pipeline config |
| security-notes.md | Security notes |
| stale-candidates.md | Review queue |
| recall-index.md | Recall summaries |

## Safe to Re-run

Init is idempotent - existing files are preserved.

## Usage

```bash
memory-init
```
