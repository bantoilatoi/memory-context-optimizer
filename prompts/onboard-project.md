# Onboard Project Prompt

Use for new project onboarding with memory.

## Process

1. Read `architecture.md`
2. Read `coding-conventions.md`
3. Check `current-work.md` for active tasks
4. Map project structure
5. Identify key files

## Onboarding Context Format

```markdown
## Project Onboarding

### Project
- Name: [name]
- Stack: [tech stack]
- Structure: [directories]

### Architecture
- [System overview from architecture.md]

### Conventions
- [Key conventions from coding-conventions.md]

### Active Work
- [From current-work.md]

### Key Files
- `src/index.js` - entry point
- `src/routes/` - API routes
- `tests/` - test files

### First Steps
1. [Recommended first action]
2. [Second action]
3. [Third action]

### Memory Files
- `.memory-context/architecture.md`
- `.memory-context/coding-conventions.md`
- `.memory-context/current-work.md`
```
